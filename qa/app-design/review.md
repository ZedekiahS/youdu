## 设计判断与技能应用

- interface-design：沿用现有绿、浅灰绿、白色表面和系统字体。使用者以手机查看当天任务、查资料、记实际摄入和运动为主。今日以安排优先；设置先呈现模块入口；不常用的配置按需展开。正文、辅助文字、数值和操作分层；单边框、12–14px 圆角，4/8px 间距节奏，数值等宽，不更换视觉体系。
- Web Design Guidelines：本轮重新读取 https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md 。检查导航语义、表单标签、焦点、选中状态、缺失内容、对比度、窄屏溢出和固定底栏。主导航改原生链接；Tab、Shift+Tab、Escape、弹窗切换与关闭后的焦点实际验证。
- UI UX Pro Max：本地检索 mobile readable text、focus not obscured。应用输入字号 16px、辅助文字至少 12px、主要按钮至少 44px、固定栏前后滚动留白；保留现成控件，未增加组件库。
- Impeccable：沿用已获取的 context，读取 polish、operate、craft-floor，按现有产品精修。源码扫描一次覆盖 Shell、Pages、Personal、Training、WorkoutBuilder、Assistant、ui、dialogs、NutritionTrace 和 product.css，结果 []，见忽略入库的 tools/impeccable-app-review.json。随后以浏览器验证修复弹窗焦点顺序和跟练紧凑展示；没有为了追求扫描数量重复检测。源码无命中不等于全项无障碍认证。
