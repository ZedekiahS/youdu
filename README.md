## 第一条体验路径：放下手机跟练

运动 → 动作库 → 原地踏步（或扶椅提踵）→ 播放示范 → 自行设置组数/次数 → 加入今天并开始 → 设置每组时间与休息 → 5 秒准备后开始跟练。

自动经过准备、练习、休息、下一组；计时结束后一次核对实际完成。支持暂停、恢复、离开再回来，示范暂停/重播不改训练总计时或已完成组数。多动作安排从“运动 → 今日训练 → 安排自己的训练”创建。训练时保持网页前台；锁屏后台不保证运行。可选本机中文语音，浏览器没有本机中文声音时明确提示，不调用云语音。

已交付 **5 个真实连续 MP4**：原地踏步 `march-in-place`（1 秒循环）、徒手浅蹲 `mini-squat`（2.4 秒）、臀桥 `glute-bridge`（4.1 秒）、鸟狗式 `bird-dog`（6.8 秒）、扶椅提踵 `calf-raise`（2.6 秒）。所有循环保持上游原节奏。列表只加载封面，详情按需加载当前视频。共 8 个动作条目：坐站练习、靠墙俯卧撑、扶椅浅蹲缺精确动画，保留 NHS 图文入口，未用相似动作顶替。遵循最小交付，暂未扩至 15–20 个；未经过专业动作审核。

来源：Shlomy Reshef 的 [Desk Break 固定提交](https://github.com/shlomorsh/desk-break/tree/8d475aa476b2c0e9ec6d09d8558faf17161e19ef)，MIT。源文件校验值在 `public/motion/source.json`；完整许可及第三方声明在 `public/licenses/`。本站做灰色材质、固定视角、支撑椅和离线视频，不修改动作姿势与节奏。手机不加载全库 GLB。

离线重建（Blender 4.5.9 是制作工具，不随网页分发）：

```powershell

```

## 第二条路径：营养溯源

饮食 → 食品营养 → 搜索“鸡蛋” → 区分生全蛋和水煮全蛋 → 查看来源、版本和逐项字段 → 输入克数 → 选择日期/餐次/称量方式 → 保存 → 饮食日记 → 更正 → 我的/全部功能 → 进度与复盘 → 点击营养总量 → 原餐次 → 食品历史版本。

80 个真实 **USDA FoodData Central SR Legacy 2018-04 历史条目**，共核对 480 个营养字段。原有 12 条保留数值、来源字段与版本，本轮新增 68 条，包含主食、蔬菜、水果、肉类、鱼类、蛋奶豆、薯类与玉米、坚果种子和调味用油；生熟变体是独立条目。数据为美国食品，中文名人工映射，**不是中国食品库，没有无标签依据的品牌食品**。来源为 USDA（CC0 / public domain），字段保留数值、单位、状态、原 CSV 行号、推导方式、地区、食物状态、版本和许可。数值为零不擅自解释为标签标零或低于定量限；上游未提供的信息仍然未知。

`public/data/food-evidence.json` 包含原始摘录、字段定义、推导依据和压缩包 SHA256。用官方固定下载包重新生成：

```powershell
python scripts/build-food-catalog.py --archive '..\data-source\usda-sr-legacy-2018.zip'
```

默认源包位于仓库外，不随源码上传；官方地址和完整 SHA256 在上述证据文件中。脚本先验证源包，再按 `scripts/food-selection.json` 的固定编号和原文核对条目；同时拒绝既有数值变动。食品列表提供分类和别名搜索。12 个自编菜谱仅按原料加总；烹调损耗、剩油、成品水分未实测，不能当成实验室分析值。菜谱、本次制作和个人摄入分开；旧餐保存食品快照。缺失字段不当零，只有早餐也不自动调整目标。

## 个人试用与边界

我的 → 创建个人档案，填写身高、目标与记录方式；体重、围度从身体页录入、更正并看趋势。报告保存原件；指标需人工填原文、位置、比较符号、单位和参考范围。没有 OCR 或医学解读。

我的 → 导出备份：包含当前档案及报告原件。导入校验结构/版本，始终新增档案，不覆盖已有档案。v1 升级 v2 前保留原始存储，不能靠清空数据升级。家庭页可为明确选定的本机档案按配方分份代记，报告和对话不在此页分享；同设备档案不是安全账户隔离。隐私四项分开：本地保存启用；同步未接入；云 AI 关闭；分享需明确选择。

AI 当前是本地规则与程序计算，支持食品候选、上下文卡片、草稿、记录汇总和旧汇总过期提示。**真实语言模型、后端凭据、跨账号权限、云同步均未接入**；个人档案不使用 10/20/30 分钟演示规则自动改计划。原有自动微调、暂停、旧确认失效和撤销逻辑仅在示例档案可体验，不能冒充个体化健康算法。没有开通或调用任何收费模型。

参考交互：[Nike Training Club 官方介绍](https://apps.apple.com/us/app/nike-training-club/id301521403)、[Hevy 组间休息](https://www.hevyapp.com/features/workout-rest-timer/)。借鉴准备/跟练/休息与统一核对，不搬用这些产品素材。
