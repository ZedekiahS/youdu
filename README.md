# 有度：全项目交互原型

临时产品名称，用于验证健康管理项目的完整体验。响应式 Web，覆盖电脑与手机尺寸；不是已上架 App 或微信小程序。

预览：<http://127.0.0.1:5178/>。服务只绑定本机。固定演示日期为 2026-11-02；示例身体数据不是用户数据。

## 当前可操作范围

- 今日总览：饮食营养、活动时间、最近体重、安排、饮水和状态。
- 饮食营养：4 份示例菜谱，10 个食品原始条目，搜索、收藏、份量调整、原料跳转、做菜步骤、备餐清单、本次制作快照、分次摄入与更正；食品详情保留来源菜谱、当前用量与查看基准。
- 运动训练：4 个带来源动作、具体训练安排、逐组训练、临时替换、离开后保留进度、执行快照与活动历史。10/20/30 分钟示例分别执行 2/6/9 组，仅关联对应计划。
- 身体资料：身高等基础资料、跨日体重、趋势、图片/PDF 原件在本地 IndexedDB 保存与预览。
- 目标计划：阶段目标、一周安排、训练执行进度、饮食与习惯手动完成状态、提醒偏好、调整历史。
- 进度复盘：7/14 天真实记录汇总；未记录日期保持空缺；点击日期返回原始日记。
- AI 助手：明确标注为本地规则演示；对话和草稿持久保留，关联记录、菜谱、食材与具体计划。开启自动微调后，10–20 分钟范围内自动应用，30 分钟等待确认；身体限制、已执行等情况暂停，可恢复已应用的调整。
- 家庭协作：本机模拟成员、菜谱与活动次数分享开关、成员可见范围预览。
- 我的与隐私：本机保存、JSON 导出、空白档案、重置前备份与恢复、来源说明。

## 数据与限制

食品数据摘自 USDA FoodData Central SR Legacy 2018-04 CSV，保留原始 FDC 编号、食物状态和出处。父目录 `data-source/` 包含官方源文件、提取脚本与溯源记录。数值为样本数据，不代表中国常见食品的完整数据库。菜谱是本站示例配方；封面是 AI 生成食物示意图。动作说明为 NHS 来源的中文简述；官方示范在原页面查看。

没有真实语言模型、OCR、账号、跨设备同步、云备份、支付、设备接入、系统通知、远程家庭授权。饮食与习惯计划的手动完成不会生成摄入。训练按实际逐组记录更新关联计划，保留开始时的执行快照；恢复计划不会重写已发生的训练。完成做菜只保存制作，实际吃掉多少另行记录。营养计算依赖录入克数和食品状态，不能当作诊疗建议。报告原件不包含在 JSON 导出中。

所有交互数据保存在当前浏览器。更换浏览器不会自动共享记录。清理浏览器站点数据会影响记录。本原型没有正式数据库或生产用户。

## 开发与复验

项目使用 React、Vite、Recharts 与 Phosphor 图标。依赖已安装。可在本目录运行 `node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5178 --strictPort`。构建命令为 `npm run build`。保留模板原有 Sites 构建支持，但未发布到外网。

首轮人工检查见 `qa/verification.md`；第二轮流程修订与桌面、390px 手机检查见 `qa/iteration-2/verification.md`。核心状态规则可运行 `node --test tests/workflows.test.mjs`（8 项）。当前原型用于讨论信息架构和业务流程，后续产品设计及正式实现不受此代码结构约束。
